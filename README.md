# klingon-localization

A Klingon (`tlh`) interface for [WordCraft](https://github.com/storytold/wordcraft), the open-source word processor, contributed through [storytold/craft-i18n](https://github.com/storytold/craft-i18n).

- [PLAN.md](PLAN.md): goal, language choices, people, phases and decisions
- [outreach/](outreach): drafts of the first public posts

Questions and glossary discussion: open an issue here with the `tlh` label.
