# klingon-localization

A Klingon (`tlh`) interface for the storytold Crafting Apps: [WordCraft](https://github.com/storytold/wordcraft) first, then PdfCraft, PhotoCraft, VectorCraft, FilmCraft, CADCraft and more. All of them share one set of translations in [storytold/craft-i18n](https://github.com/storytold/craft-i18n), so Klingon done once shows up across the suite.

- [PLAN.md](PLAN.md): goal, language choices, people, waves, per-app tracker and decisions
- [outreach/](outreach): drafts of the first public posts

Questions and glossary discussion: open an issue here with the `tlh` label.
